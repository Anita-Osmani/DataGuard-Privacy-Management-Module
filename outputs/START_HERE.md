# DataGuard — Hapat e ardhshëm

## 1. Vendos demo data

1. Hape Supabase → SQL Editor → New query.
2. Kopjo përmbajtjen e `supabase/demo_seed.sql`.
3. Kliko Run.
4. Bëj refresh te DataGuard.

Do të krijohen një Customer Privacy Policy, versioni 1.0, tri retention policies dhe dy customers.

## 2. Krijo account User për demonstrim

1. Dil nga Admin.
2. Krijo një account të ri me email tjetër.
3. Lëre rolin e tij `user`.
4. Hyni si User, hapni My Privacy dhe pranoni policy-n.
5. Krijoni Data Export Request dhe Data Deletion Request.

## 3. Hyni përsëri si Admin

1. Hapni Data Requests.
2. Approve një kërkesë.
3. Klikoni Mark completed.
4. Hapni Audit Logs dhe tregoni veprimet e regjistruara.

## 4. Merrni screenshots për diplomë
